## 2026-10-20 - User file DB fallback mtime caching & native base64url
**Learning:** Uncached file-system fallbacks in serverless auth utilities cause synchronous disk I/O and JSON parsing overhead on every authentication check. Caching the parsed user map and checking `fs.statSync(file).mtimeMs` avoids repeated file reads while ensuring immediate cache invalidation when users are updated. Additionally, using Node.js native `"base64url"` buffer encoding/decoding and HMAC digest removes regex string allocations in JWT operations.
**Action:** When working with file-backed JSON stores in Node.js serverless functions, always use lightweight `mtimeMs` stat checks to serve read operations from memory, and use native `"base64url"` buffer capabilities instead of regex string replaces.
