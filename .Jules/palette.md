## 2026-10-12 - Multilingual Accessible Action Labels
**Learning:** For bilingual language toggle controls displaying target language text (e.g. "বাংলা"), screen readers need descriptive action-oriented `aria-label` attributes that dynamically update with the selected language state to clearly communicate the action of switching languages.
**Action:** Always provide and dynamically update `aria-label` when toggling language states in multilingual UI buttons.
